This is a Python project for my 2024 Calculus III class. This project asked for a derivation for an epitrochoid. I used Manim, a library for math animations, to code and explain how to derive an epitrochoid from just two circles.

The derivation can be viewed from the YouTube link below:

https://youtu.be/JHmZCTwXHbY


NOTE: This commit only contains the main.py file because the library was too large to upload to GitHub. You may need to create the Python environment yourself before activating the main.py file. I used miniconda and installed the Manim library directly into the virtual environment.
